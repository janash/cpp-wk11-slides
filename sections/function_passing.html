Review: Limitations of C Style Arrays

Review

  • C-style arrays are data structures that hold multiple values of the same type.
  • Typically have fixed size determined at compile time.
  • Declare with size (int arr[10])
  • Can loop over an index into.

Limitations:

No bounds check, difficult to have variable sizes (must use pointers)

#include <iostream> // for std::cout, std::endl

int main(void)
{
    int arr[5] = {10, 20, 30, 40, 50};
    
    for(int i = 0; i < 5; i++)
    {
        std::cout << "Element " << i << ": " << 
                    arr[i] << std::endl;
    }
    
    return 0;
}
Fixed size - must know at compile time!
Manual size tracking - error prone!
Python for Molecular Sciences:
Safer Alternative: std::array

We can solve one (bounds checking) of these problems with std::array!

  • Wrapper for C-style array
  • Size must be known at compile time!
  • include array to use std::array
  • std::array of type int, size 5 elements
  • The array "knows" its size.
#include <array>
#include <iostream>

int main() {
    // C-style array - unsafe
    int c_array[5] = {10, 20, 30, 40, 50};
    
    // std::array - safe wrapper
    std::array<int, 5> safe_array = {10, 20, 30, 40, 50};
    
    std::cout << "Size: " << safe_array.size() << std::endl;
    std::cout << "Max size: " << safe_array.max_size() << 
                std::endl;
    
    return 0;
}
Need to include <array> header
Template: type and size
Built-in size methods!
Python for Molecular Sciences:
std::array – Accessing Data

Two Ways to Access:

[] Operator

  • Fast access
  • No bounds checking
  • Same as C arrays

.at() Method

  • Bounds checking
  • Throws exception if out of bounds
  • Safer but slightly slower
  • This is the preferred method for accessing elements in std::array
int main() {
    std::array<int, 5> safe_array = {10, 20, 30, 40, 50};
    
    // Can access using [] 
    // No bounds checking, same as with C arrays
    std::cout << safe_array[0] << std::endl;
    
    // Can access using .at()
    // BETTER! Checks size.
    std::cout << safe_array.at(0) << std::endl;
    
    return 0;
}
Unsafe - no checking!
Safe - bounds checked!

Introducing std::vector

For dynamic sizing, use `std::vector`

  • Allows dynamic resizing – if number of elements isn't known at compile time.
  • #include <vector>
  • Manages its own memory
#include <vector>
#include <iostream>

int main() {
    // Empty vector
    std::vector<int> numbers;
    
    // Add elements dynamically
    numbers.push_back(42);
    numbers.push_back(17);
    numbers.push_back(99);
    
    std::cout << "Size: " << numbers.size() << std::endl;
    std::cout << "First: " << numbers[0] << std::endl;
    
    return 0;
}
Starts empty!
Grows dynamically

Essential Vector Methods

Key Vector Methods:

  • .size() - returns number of elements
  • push_back- adds an element to the end of the vector.
  • .front()/.back() - access first/last element
  • .at(index) - safe access with bounds checking
  • .empty() - check if vector is empty

💡 Note: Other useful methods like .pop_back() and .clear() exist - explore them in the exercises!

#include <vector>
#include <iostream>

int main() {
    std::vector<int> data = {10, 20, 30};
    
    // Check size
    std::cout << "Size: " << data.size() << std::endl;
    
    // Check if empty
    std::cout << "Empty? " << data.empty() << std::endl;
    
    // Access first and last elements
    std::cout << "First: " << data.front() << std::endl;
    std::cout << "Last: " << data.back() << std::endl;
    
    // Safe access by index
    std::cout << "Second element: " << data.at(1) << std::endl;
    
    return 0;
}

Container Loops with size_t

Use size_t for Container Loops

When looping through containers, use size_t instead of int:

  • Matches what .size() returns
  • No compiler warnings
  • Prevents negative indices
  • Works with both std::array and std::vector

Best Practice: Always use size_t for container indices!

#include <vector>
#include <array>
#include <iostream>

int main() {
    std::vector<int> vec = {10, 20, 30, 40, 50};
    std::array<int, 3> arr = {1, 2, 3};
    
    // Correct: use size_t for both containers
    for(size_t i = 0; i < vec.size(); i++) {
        std::cout << vec[i] << " ";
    }
    std::cout << std::endl;
    
    for(size_t i = 0; i < arr.size(); i++) {
        std::cout << arr.at(i) << " ";
    }
    std::cout << std::endl;
    
    return 0;
}
No warnings with vectors
Python for Molecular Sciences:
Accessing Vector Elements

Same as std::array:

  • [] operator - Fast, no bounds checking
  • .at() method - Safe, bounds checked
  • .front() and .back() - First and last elements

⚠️ Important: Same safety rules apply - use .at() for bounds checking!

#include <vector>
#include <iostream>

int main() {
    std::vector<int> data = {100, 200, 300, 400, 500};

    // Unsafe but fast
    std::cout << data[0] << std::endl;        // 100
    std::cout << data[4] << std::endl;        // 500

    // Safe with bounds checking
    std::cout << data.at(0) << std::endl;    // 100
    // std::cout << data.at(10) << std::endl; // Exception!

    // Convenient methods
    std::cout << data.front() << std::endl;  // 100
    std::cout << data.back() << std::endl;     // 500

    // Check size first
    if(!data.empty()) {
        std::cout << "Safe access!" << std::endl;
    }
    
    return 0;
}
Bounds checked

std::map

std::map - Key-Value Storage

  • Like Python dictionaries
  • Keys must be unique
  • Automatically sorted by key
  • #include <map>

Key → Value Mapping:

"hydrogen" → 1.008
"carbon" → 12.011
"oxygen" → 15.999 
#include <map>
#include <string>
#include <iostream>

int main() {
    // Create a map: string → double
    std::map<std::string, double> atomic_weights;
    
    // Insert key-value pairs
    atomic_weights["hydrogen"] = 1.008;
    atomic_weights["carbon"] = 12.011;
    atomic_weights["oxygen"] = 15.999;
    
    std::cout << "Map size: " << atomic_weights.size() << std::endl;
    
    return 0;
}
Template: Key type, Value type
[] operator for insertion

Accessing Map Values

Two Ways to Access:

  • [] operator: Creates key if missing
  • .at() method: Safe access, throws if missing
#include <map>
#include <string>
#include <iostream>

int main() {
    std::map<std::string, double> atomic_weights;
    atomic_weights["hydrogen"] = 1.008;
    atomic_weights["carbon"] = 12.011;
    
    // Access by key
    std::cout << "Hydrogen: " << 
                atomic_weights["hydrogen"] << std::endl;
    
    // Safe access
    std::cout << "Carbon: " << 
                atomic_weights.at("carbon") << std::endl;
    
    return 0;
}

Python for Molecular Sciences:
std::map Operations and Safety

Important Operations:

  • .find() - Safe way to check if key exists
  • .at() - Safe access (throws if missing)
  • [] - Creates key if missing!

⚠️ Warning: map["missing_key"] silently creates the key with default value!

#include <map>
#include <string>
#include <iostream>

int main() {
    std::map<std::string, double> atomic_weights;
    atomic_weights["hydrogen"] = 1.008;
    atomic_weights["carbon"] = 12.011;

    // Safe way to check if key exists
    if(atomic_weights.find("oxygen") != atomic_weights.end()) {
        std::cout << atomic_weights["oxygen"] << std::endl;
    } else {
        std::cout << "oxygen not found" << std::endl;
    }

    // This creates a new entry with default value!
    std::cout << atomic_weights["oxygen"] << std::endl;  // 0.0

    // Note: This line would cause the program to crash!
    // std::cout << atomic_weights.at("helium") << std::endl;
    
    return 0;
}
Creates key silently!
