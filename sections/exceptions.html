Python vs C++ - Exception Handling

Python Exceptions

You're already familiar with Python's approach:

  • Automatic exception throwing
  • try/except/finally blocks
  • Built-in exception types

def divide_numbers(a, b):
    try:
        result = a / b
        print(f"Result: {result}")
    except ZeroDivisionError:
        print("Cannot divide by zero!")
    except TypeError:
        print("Invalid types for division")
    finally:
        print("Division attempt completed")

# Python automatically throws exceptions
divide_numbers(10, 0)  # ZeroDivisionError
divide_numbers("a", 5)  # TypeError

C++ Exceptions

C++ has similar concepts but different syntax:

  • try/catch/finally blocks
  • Manual exception throwing with throw
  • Standard library exception types

#include <iostream>
#include <stdexcept>

void divideNumbers(double a, double b) {
    try {
        if (b == 0) {
            throw std::runtime_error("Cannot divide by zero!");
        }
        double result = a / b;
        std::cout << "Result: " << result << std::endl;
    }
    catch (const std::runtime_error& e) {
        std::cout << "Error: " << e.what() << std::endl;
    }
}

// Must explicitly check and throw
divideNumbers(10.0, 0.0);

Basic Exception Syntax

The try-catch Structure

C++ exception handling has three main parts:

try block

Code that might throw an exception

catch block

Handles specific exception types

throw statement

Creates and throws an exception


#include <iostream>
#include <stdexcept>

int main() {
    try {
        int age;
        std::cout << "Enter age: ";
        std::cin >> age;
        
        if (age < 0) {
            throw std::invalid_argument("Age cannot be negative");
        }
        
        std::cout << "Age is: " << age << std::endl;
    }
    catch (const std::invalid_argument& e) {
        std::cout << "Input error: " << e.what() << std::endl;
    }
    catch (...) {
        std::cout << "Unknown error occurred" << std::endl;
    }
    
    return 0;
}
Code that might fail
Manually throw an exception
Handle specific exception type
Catch any remaining exceptions

Common Exception Types

Standard Library Exceptions

C++ provides several built-in exception types:

std::runtime_error
General runtime problems
std::invalid_argument
Bad function parameters
std::out_of_range
Array/vector index errors
std::bad_alloc
Memory allocation failures

Note: Must #include <stdexcept> for most exception types


#include <iostream>
#include <stdexcept>
#include <vector>

void demonstrateExceptions() {
    try {
        // Different types of exceptions
        throw std::runtime_error("Something went wrong");
        
        throw std::invalid_argument("Bad parameter value");
        
        // Vector out of range
        std::vector<int> numbers = {1, 2, 3};
        std::cout << numbers.at(10);  // Throws out_of_range
        
    }
    catch (const std::runtime_error& e) {
        std::cout << "Runtime error: " << e.what() << std::endl;
    }
    catch (const std::invalid_argument& e) {
        std::cout << "Invalid argument: " << e.what() << std::endl;
    }
    catch (const std::out_of_range& e) {
        std::cout << "Out of range: " << e.what() << std::endl;
    }
}

Multiple Catch Blocks

Handling Different Exception Types

You can have multiple catch blocks for different scenarios:

  • Specific first: More specific exceptions should be caught before general ones
  • Order matters: First matching catch block is executed
  • Catch all: catch(...) catches any exception

Important: Put more specific exceptions before general ones, or they'll never be reached!


#include <iostream>
#include <stdexcept>
#include <vector>

void processVector(std::vector<int>& vec, int index, int value) {
    try {
        if (value < 0) {
            throw std::invalid_argument("Value must be positive");
        }
        
        vec.at(index) = value;  // Might throw out_of_range
        
        std::cout << "Successfully set vec[" << index << "] = " << value << std::endl;
    }
    catch (const std::invalid_argument& e) {
        std::cout << "Invalid input: " << e.what() << std::endl;
    }
    catch (const std::out_of_range& e) {
        std::cout << "Index error: " << e.what() << std::endl;
    }
    catch (const std::exception& e) {
        std::cout << "Other error: " << e.what() << std::endl;
    }
}
Specific exceptions first
General exception catches anything else

Exception Best Practices

When and How to Use Exceptions

✓ Good Uses

  • Unexpected error conditions
  • Invalid user input
  • Resource allocation failures
  • File I/O errors

✗ Avoid For

  • Normal program flow control
  • Expected conditions
  • Performance-critical code

💡 Tips

  • Always catch by const reference
  • Use meaningful error messages
  • Clean up resources properly

#include <iostream>
#include <stdexcept>
#include <fstream>

// ✓ Good: Validate input and throw meaningful errors
double calculateSquareRoot(double x) {
    if (x < 0) {
        throw std::invalid_argument(
            "Cannot calculate square root of negative number: " + 
            std::to_string(x)
        );
    }
    return sqrt(x);
}

// ✓ Good: Catch by const reference
void safeCalculation() {
    try {
        double result = calculateSquareRoot(-5.0);
    }
    catch (const std::invalid_argument& e) {
        std::cout << "Error: " << e.what() << std::endl;
        // Handle error appropriately
    }
}

// ✗ Bad: Using exceptions for control flow
void badExample() {
    try {
        for (int i = 0; ; ++i) {
            processItem(i);  // Throws when no more items
        }
    }
    catch (const std::out_of_range&) {
        // Don't use exceptions to exit loops!
    }
}

Real-World Example

File Processing with Exception Handling

A practical example combining multiple concepts:

  • File operations can fail in many ways
  • Input validation prevents bad data
  • Multiple catch blocks handle different errors
  • Resource cleanup happens automatically

Result: Code that handles errors and provides helpful feedback.


#include <iostream>
#include <fstream>
#include <stdexcept>
#include <vector>

std::vector<double> readNumbers(const std::string& filename) {
    std::vector<double> numbers;
    
    try {
        std::ifstream file(filename);
        if (!file.is_open()) {
            throw std::runtime_error("Could not open file: " + filename);
        }
        
        double value;
        while (file >> value) {
            if (value < 0) {
                throw std::invalid_argument("Negative values not allowed");
            }
            numbers.push_back(value);
        }
        
    }
    catch (const std::invalid_argument& e) {
        std::cout << "Data error: " << e.what() << std::endl;
        throw;  // Re-throw to caller
    }
    catch (const std::runtime_error& e) {
        std::cout << "File error: " << e.what() << std::endl;
        throw;  // Re-throw to caller
    }
    
    return numbers;
}
