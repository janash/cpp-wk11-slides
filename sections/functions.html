Pass-by-Value Review

Remember: "Pass-by-Value"

You learned that C++ copies arguments by default:

  • Function gets a copy of the argument
  • Changes inside function don't affect original
  • This is the default behavior in C++
  • Works well for small data types like int, double

Memory Cost: Each copy uses additional memory

#include <iostream>

void tryToDouble(int num) {
    std::cout << "Inside function, before: " << num << std::endl;
    num = num * 2;
    std::cout << "Inside function, after: " << num << std::endl;
}

int main() {
    int value = 10;
    std::cout << "Before function: " << value << std::endl;
    
    tryToDouble(value);
    
    std::cout << "After function: " << value << std::endl;
    
    return 0;
}
Modifying the copy, not original
value is still 10 - just like you learned!

The Problem: Trying to Swap Variables

A Common Problem:

Let's try to write a function that swaps two variables:

Problem: This function doesn't work! Why?

Expected: a=20, b=10
Actual: a=10, b=20 (unchanged)

#include <iostream>

void swap(int x, int y) {
    int temp = x;
    x = y;
    y = temp;
    std::cout << "Inside swap: x=" << x << ", y=" << y << std::endl;
}

int main() {
    int a = 10;
    int b = 20;
    
    std::cout << "Before: a=" << a << ", b=" << b << std::endl;
    
    swap(a, b);
    
    std::cout << "After: a=" << a << ", b=" << b << std::endl;
    
    return 0;
}
Remember: x and y are copies of a and b
Swapping copies has no effect on originals

Pass-by-Reference Solution

Pass-by-Reference with &:

  • Parameter is an alias to the original
  • Changes affect the original variable
  • No copying - more efficient
  • Use & in parameter declaration

Key: The & makes the parameter a reference, not a copy

#include <iostream>

void swap(int& x, int& y) {
    int temp = x;
    x = y;
    y = temp;
    std::cout << "Inside swap: x=" << x << ", y=" << y << std::endl;
}

int main() {
    int a = 10;
    int b = 20;
    
    std::cout << "Before: a=" << a << ", b=" << b << std::endl;
    
    swap(a, b);
    
    std::cout << "After: a=" << a << ", b=" << b << std::endl;
    
    return 0;
}
& makes x and y aliases to a and b
Now the swap actually works!

Python for Molecular Sciences:
Const References for Containers

Solution: Const References

  • const& avoids copying containers
  • Much more efficient for large vectors
  • Prevents accidental modifications
  • Use size_t for container indices

Best Practice: Always use const& for containers you only read

#include <vector>
#include <array>
#include <iostream>

// GOOD: No copying, efficient
void printVector(const std::vector<int>& vec) {
    std::cout << "Vector size: " << vec.size() << std::endl;
    for (size_t i = 0; i < vec.size(); i++) {
        std::cout << vec[i] << " ";
    }
    std::cout << std::endl;
}

void printArray(const std::array<int, 5>& arr) {
    for (size_t i = 0; i < arr.size(); i++) {
        std::cout << arr[i] << " ";
    }
}

int main() {
    std::vector<int> numbers = {1, 2, 3, 4, 5};
    std::array<int, 5> data = {10, 20, 30, 40, 50};
    
    printVector(numbers);  // No copying!
    printArray(data);     // No copying!
    
    return 0;
}
const& prevents copying and modification
Remember: use size_t for container indices
Much more efficient - no copying!

Arrays: You've Seen This Before

Remember how arrays behave differently with functions:

  • Arrays don't follow pass-by-value rules
  • They automatically "decay" to pointers
  • Changes to array elements affect the original
  • This is why you pass array size separately

Key Point: Arrays are the exception to pass-by-value

#include <iostream>

void process_array(int arr[], int size) {
    for (int i = 0; i < size; i++) {
        arr[i] = arr[i] * 2;
    }
}

int main() {
    int numbers[5] = {10, 20, 30, 40, 50};
    
    std::cout << "Before: ";
    for (int i = 0; i < 5; i++) {
        std::cout << numbers[i] << " ";
    }
    std::cout << std::endl;
    
    process_array(numbers, 5);
    
    std::cout << "After: ";
    for (int i = 0; i < 5; i++) {
        std::cout << numbers[i] << " ";
    }
    std::cout << std::endl;
    
    return 0;
}
You learned this: arrays pass addresses
This is why original array gets modified

When to Use Each Approach
Type Method When to Use Example
Small types Pass-by-value Don't want to modify original int, double, char
Any type Pass-by-reference (&) Need to modify the original swap function, input functions
Containers Const reference (const&) Large objects, only need to read std::vector, std::array, std::string

Key Takeaway

C-style arrays: automatic pointer behavior • std::vector/std::array: normal pass-by-value (use const& for efficiency)

Python for Molecular Sciences:
Common Mistakes

Watch Out For:

Mistake 1: Forgetting & when you want to modify

Mistake 2: Using & when you don't need to modify

Mistake 3: Forgetting const with references

// Mistake 1: Forgot &, won't modify original
void setBad(int x) {
    x = 100;  // Only changes copy
}

// Correct: Use & to modify original
void setGood(int& x) {
    x = 100;  // Changes original
}

// Mistake 2: Unnecessary & for reading
void printBad(int& x) {
    std::cout << x;  // Could be const&
}

// Better: Use const& for reading
void printGood(const int& x) {
    std::cout << x;  // Safe and clear intent
}
Won't modify the original variable
Will modify the original variable
