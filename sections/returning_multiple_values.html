Returning Multiple Values

When one return value isn't enough

Python for Molecular Sciences:
The Problem

Sometimes We Need Multiple Results

Some calculations naturally produce multiple values:

  • Division: quotient and remainder
  • Coordinates: x and y values
  • Statistics: mean and standard deviation
  • Min/max: both minimum and maximum

Problem: C++ functions can only return one value directly.


#include <iostream>

// This doesn't work - can't return two values
// int, int divide(int a, int b) {  // ERROR!
//     return a / b, a % b;
// }

// Inefficient - need separate function calls
int quotient(int a, int b) {
    return a / b;
}

int remainder(int a, int b) {
    return a % b;
}

int main() {
    int q = quotient(17, 5);  // 17/5 = 3
    int r = remainder(17, 5); // 17%5 = 2
    
    std::cout << q << " remainder " << r << std::endl;
    return 0;
}
Two separate calculations of the same division

Solution 1: Reference Parameters

Use References for "Output" Parameters

We can use reference parameters to "return" multiple values:

  • Function modifies variables through references
  • Caller gets multiple results
  • More efficient than separate calculations

Pattern: Pass variables by reference to receive results


#include <iostream>

void divide(int a, int b, int& quotient, int& remainder) {
    quotient = a / b;
    remainder = a % b;
}

int main() {
    int q, r;  // Variables to receive results
    
    divide(17, 5, q, r);  // Pass by reference
    
    std::cout << q << " remainder " << r << std::endl;
    return 0;
}
References allow function to modify caller's variables
After this call, q=3 and r=2

Solution 2: std::pair

Package Two Values Together

std::pair lets you bundle two values into one return value:

  • Template that holds two values of any types
  • Access with .first and .second
  • Can return as a single value

Benefit: Clean function interface, true return value
