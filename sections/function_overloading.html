Function Overloading

Same name, different parameters

Python vs C++ - Function Names

Python Approach

One function name = one function

In Python, if you want different behavior, you typically:

  • Use different function names
  • Use default parameters
  • Check parameter types inside the function

def area_circle(radius):
    return 3.14159 * radius * radius

def area_rectangle(length, width):
    return length * width

def area_triangle(base, height):
    return 0.5 * base * height

# Different names for different shapes
print(area_circle(5.0))
print(area_rectangle(4.0, 6.0))
print(area_triangle(3.0, 8.0))

C++ Approach

One logical name, multiple implementations

C++ allows function overloading:

  • Same intuitive name for related operations
  • Compiler chooses the right function automatically
  • Based on parameter types and count

double area(double radius) {
    return 3.14159 * radius * radius;
}

double area(double length, double width) {
    return length * width;
}

double area(double base, double height, bool triangle) {
    return 0.5 * base * height;
}

// Same name, compiler picks the right one
std::cout << area(5.0) << std::endl;
std::cout << area(4.0, 6.0) << std::endl;
std::cout << area(3.0, 8.0, true) << std::endl;

Function Overloading

Multiple Functions, Same Name

C++ allows multiple functions with the same name if they have different parameters:

  • Different number of parameters
  • Different types of parameters
  • Compiler chooses the right one automatically

Benefit: One intuitive name for related operations


#include <iostream>

double area(double radius) {
    return 3.14159 * radius * radius;  // Circle
}

double area(double length, double width) {
    return length * width;  // Rectangle
}

double area(double base, double height, bool triangle) {
    return 0.5 * base * height;  // Triangle
}

int main() {
    std::cout << area(5.0) << std::endl;        // Circle
    std::cout << area(4.0, 6.0) << std::endl;   // Rectangle
    std::cout << area(3.0, 8.0, true) << std::endl; // Triangle
    
    return 0;
}
One parameter → circle area
Two parameters → rectangle area
Three parameters → triangle area

Overloading Rules

What Makes Functions Different?

Functions can be overloaded based on:

✓ Valid Differences

  • Number of parameters
  • Types of parameters
  • Order of parameter types

✗ Not Valid

  • Only return type differs
  • Only parameter names differ

// ✓ Valid overloads
void print(int x);
void print(double x);
void print(int x, int y);

// ✗ Invalid - only return type differs
int calculate(double x);
double calculate(double x);  // ERROR!

// ✗ Invalid - only parameter name differs  
void process(int value);
void process(int number);  // ERROR!

// ✓ Valid - different parameter order
void mix(int a, double b);
void mix(double a, int b);

Returning Multiple Values

When one return value isn't enough

Python for Molecular Sciences:
The Problem

Sometimes We Need Multiple Results

Some calculations naturally produce multiple values:

  • Division: quotient and remainder
  • Coordinates: x and y values
  • Statistics: mean and standard deviation
  • Min/max: both minimum and maximum

Problem: C++ functions can only return one value directly.


#include <iostream>

// This doesn't work - can't return two values
// int, int divide(int a, int b) {  // ERROR!
//     return a / b, a % b;
// }

// Inefficient - need separate function calls
int quotient(int a, int b) {
    return a / b;
}

int remainder(int a, int b) {
    return a % b;
}

int main() {
    int q = quotient(17, 5);  // 17/5 = 3
    int r = remainder(17, 5); // 17%5 = 2
    
    std::cout << q << " remainder " << r << std::endl;
    return 0;
}
Two separate calculations of the same division

Solution 1: Reference Parameters

Use References for "Output" Parameters

We can use reference parameters to "return" multiple values:

  • Function modifies variables through references
  • Caller gets multiple results
  • More efficient than separate calculations

Pattern: Pass variables by reference to receive results


#include <iostream>

void divide(int a, int b, int& quotient, int& remainder) {
    quotient = a / b;
    remainder = a % b;
}

int main() {
    int q, r;  // Variables to receive results
    
    divide(17, 5, q, r);  // Pass by reference
    
    std::cout << q << " remainder " << r << std::endl;
    return 0;
}
References allow function to modify caller's variables
After this call, q=3 and r=2

Solution 2: std::pair

Package Two Values Together

std::pair lets you bundle two values into one return value:

  • Template that holds two values of any types
  • Access with .first and .second
  • Can return as a single value

Benefit: Clean function interface, true return value


#include <iostream>
#include <utility>  // for std::pair

std::pair<int, int> divide(int a, int b) {
    return std::make_pair(a / b, a % b);
}

int main() {
    std::pair<int, int> result = divide(17, 5);
    
    std::cout << result.first << " remainder " 
              << result.second << std::endl;
    
    // Or unpack immediately
    auto [q, r] = divide(17, 5);  // C++17 feature
    
    return 0;
}
Returns a pair containing quotient and remainder
Modern C++ can unpack pairs automatically

Choosing Your Approach

When to Use Each Approach

Reference Parameters

void func(int& a, int& b)

Best for:

  • More than 2 return values
  • Large objects (avoid copying)
  • When some outputs are optional

std::pair

pair<int, int> func()

Best for:

  • Exactly 2 return values
  • Small, simple types
  • Clean mathematical functions

Quick Decision Guide

2 small values? Use std::pair. 3+ values or large objects? Use reference parameters.
