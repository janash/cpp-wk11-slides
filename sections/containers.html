Review: Limitations of C Style Arrays

Review

  • C-style arrays are data structures that hold multiple values of the same type.
  • Typically have fixed size determined at compile time.
  • Declare with size (int arr[10])
  • Can loop over an index into.

Limitations:

No bounds check, difficult to have variable sizes (must use pointers)

#include <iostream> // for std::cout, std::endl

int main(void)
{
    int arr[5] = {10, 20, 30, 40, 50};
    
    for(int i = 0; i < 5; i++)
    {
        std::cout << "Element " << i << ": " << 
                    arr[i] << std::endl;
    }
    
    return 0;
}
Fixed size - must know at compile time!
Manual size tracking - error prone!

Safer Alternative: std::array

We can solve one (bounds checking) of these problems with std::array!

  • Wrapper for C-style array
  • Size must be known at compile time!
  • include array to use std::array
  • std::array of type int, size 5 elements
  • The array "knows" its size.
#include <array>
#include <iostream>

int main() {
    // C-style array - unsafe
    int c_array[5] = {10, 20, 30, 40, 50};
    
    // std::array - safe wrapper
    std::array<int, 5> safe_array = {10, 20, 30, 40, 50};
    
    std::cout << "Size: " << safe_array.size() << std::endl;
    std::cout << "Max size: " << safe_array.max_size() << 
                std::endl;
    
    return 0;
}
Need to include <array> header
Template: type and size
Built-in size methods!

Python for Molecular Sciences:
std::array – Accessing Data

Two Ways to Access:

[] Operator

  • Fast access
  • No bounds checking
  • Same as C arrays

.at() Method

  • Bounds checking
  • Throws exception if out of bounds
  • Safer but slightly slower
  • This is the preffered method for accessing elements in std::array 
int main() {
    std::array<int, 5> safe_array = {10, 20, 30, 40, 50};
    
    // Can access using [] 
    // No bounds checking, same as with C arrays
    std::cout << safe_array[0] << std::endl;
    
    // Can access using .at()
    // BETTER! Checks size.
    std::cout << safe_array.at(0) << std::endl;
    
    return 0;
}
Unsafe - no checking!
Safe - bounds checked!

Introducing std::vector
For dynamic sizing, use `std::vector`
  • Allows dynamic resizing – if number of elements isn't known at compile time.
  • #include <vector>
  • Manages its own memory
#include <vector>
#include <iostream>

int main() {
    // Empty vector
    std::vector<int> numbers;
    
    // Add elements dynamically
    numbers.push_back(42);
    numbers.push_back(17);
    numbers.push_back(99);
    
    std::cout << "Size: " << numbers.size() << std::endl;
    std::cout << "First: " << numbers[0] << std::endl;
    
    return 0;
}
Starts empty!
Grows dynamically

size_t Type:

• Unsigned integer type
• Used for array indices and sizes
• Prevents negative size bugs

// 1. Empty vector
std::vector<int> empty_vec;

// Proper loop with size_t
for(size_t i = 0; i < temps.size(); i++) {

Accessing Vector Elements

Same as std::array:

  • [] operator - Fast, no bounds checking
  • .at() method - Safe, bounds checked
  • .front() and .back() - First and last elements

⚠️ Important: Same safety rules apply - use .at() for bounds checking!

std::vector<int> data = {100, 200, 300, 400, 500};

// Unsafe but fast
std::cout << data[0] << std::endl;        // 100
std::cout << data[4] << std::endl;        // 500

// Safe with bounds checking
std::cout << data.at(0) << std::endl;    // 100
// std::cout << data.at(10) << std::endl; // Exception!

// Convenient methods
std::cout << data.front() << std::endl;  // 100
std::cout << data.back() << std::endl;     // 500

// Check size first
if(!data.empty()) {
    std::cout << "Safe access!" << std::endl;
}

std::vector in Loops

Looping Through Vectors:

  • Use indexed for loop - same as arrays
  • Use .size() method for loop condition
  • Access with [] or .at()

Key Difference from C Arrays:

• Vector knows its own size with .size()

• No need to track size manually

• Much safer than C-style arrays!

std::vector<int> numbers = {10, 20, 30, 40, 50};

// Loop through vector with index
for(int i = 0; i < numbers.size(); i++) {
    std::cout << "Index " << i << ": " << numbers[i] << std::endl;
}

// Or use size_t to match .size() return type
for(size_t i = 0; i < numbers.size(); i++) {
    std::cout << numbers[i] << " ";
}
std::cout << std::endl;

// Can modify elements in loop
for(int i = 0; i < numbers.size(); i++) {
    numbers[i] *= 2;  // Double each value
}
Vector knows its size!
size_t matches .size() type
Can modify elements

std::vector vs. std::array

When to use which?

std::array

  • Size known at compile time
  • Small, fixed collections
  • Mathematical vectors (3D coordinates)
  • Very fast performance

std::vector

  • Size unknown at compile time
  • Need to grow/shrink at runtime
  • Most general-purpose container
  • Similar to Python lists
// std::array - when size is known
std::array<double, 3> position = {x, y, z};
std::array<const char*, 7> days = {
    "Mon", "Tue", "Wed", "Thu", "Fri", "Sat", "Sun"
};

// std::vector - when size varies
std::vector<double> measurements;  // Start empty
while(reading_data) {
    measurements.push_back(next_value);
}

// std::vector - user input determines size
int n;
std::cin >> n;
std::vector<int> user_data(n);  // Size from user

std::map

Key-Value Storage

  • Like Python dictionaries
  • Keys must be unique
  • Automatically sorted by key
  • #include <map>

Key → Value Mapping:

#include <map>
#include <string>
#include <iostream>

int main() {
    // Create a map: string → int
    std::map<std::string, int> ages;
    
    // Insert key-value pairs
    ages["Alice"] = 25;
    ages["Bob"] = 30;
    ages["Charlie"] = 28;
    
    // Access values by key
    std::cout << "Alice is " << ages["Alice"] << std::endl;
    std::cout << "Map size: " << ages.size() << std::endl;
    
    return 0;
}

std::map Operations and Safety

Important Operations:

  • .find() - Safe way to check if key exists
  • .at() - Safe access (throws if missing)
  • [] - Creates key if missing!

⚠️ Warning: map["missing_key"] silently creates the key with default value!

std::map<std::string, double> scores;
scores["test1"] = 95.5;
scores["test2"] = 87.2;

// Safe way to check if key exists
if(scores.find("test3") != scores.end()) {
    std::cout << scores["test3"] << std::endl;
} else {
    std::cout << "test3 not found" << std::endl;
}

// This creates a new entry with default value!
std::cout << scores["test3"] << std::endl;  // 0.0

// Safe access with .at() - throws exception
try {
    std::cout << scores.at("test4") << std::endl;
} catch(const std::out_of_range& e) {
    std::cout << "Key not found!" << std::endl;
}
Safe key checking
Creates key silently!

Container Summary

📊 std::array

  • Fixed size, compile-time constant
  • Very fast access
  • Use for: coordinates, small fixed collections

📈 std::vector

  • Dynamic size, runtime flexibility
  • Automatic memory management
  • Use for: most general-purpose needs

🗺️ std::map

  • Key-value pairs, automatic sorting
  • Unique keys only
  • Use for: lookups, associations
// Fixed size, compile-time constant
std::array<int, 3> coords = {x, y, z};

// Dynamic size, grows as needed
